What's new

Workspace changes recorded October 28, 2026; this is a curated changelog, not a live activity feed.

  • Assignment examples now have local pages of ten rows with keyboard-accessible Previous/Next buttons and a loaded-row count. Paging changes only the display; model controls remain disabled.
  • FFXI readiness now explicitly shows Unknown when the snapshot has no summary or missing fields. Feed availability still does not prove playable behavior or deployment.
  • Audit examples now have a local search by actor, action, scope or result. The count covers loaded examples only; Clear audit filter restores them. No live audit source or write action is connected.
  • New October 29: inspect a learning need and open “FFXI learning evidence checklist (read-only)”. It explains missing evidence without inferring game outcomes from task status. “Preview synthetic evidence mapping” shows independent examples; “Show selected need evidence” restores the record.
  • FFXI interaction state: use “Preview synthetic interaction” to compare current-view and raw-snapshot freshness without any hub call. The optional read-only candidate check remains unavailable until hub access is configured; it changes no switches.
  • In learning needs, open “Dataset and policy examples” to compare synthetic validation, adoption and outcome states, or open “Game learning planning checklist” to show planned topics and toggle “Show known attention statuses only” to filter loaded task records; in issues, toggle “Show issues linked to the selected bot” after selecting a bot. Both filter loaded records only.
  • From bot example evidence, use “View example episode in ledger” to filter the synthetic ledger. When hub data is selected, a ledger search can request a bounded read-only hub trace. Learning needs and issues can be searched and filtered; task issues link to learning details, and the FFXI bridge fault is shown as historical evidence.
  • The gates and stop-controls card shows synthetic examples only; actual states are unknown and the buttons are disabled.
  • Lead timeline, nudge history and cached quota observations show their source and coverage. The FFXI chat bridge card shows read-only unit and fault-marker status.
  • Use the “Bot and learning data source” selector to switch between synthetic examples and configured read-only hub views; the hub is currently unconfigured pending the token-file location.
  • Inspect a bot to see its reported personality summary and synthetic goal, memory, reply-source and fallback examples; metadata and delivery stay separate from demonstrated behavior. In the bot roster, open “Model routing (read-only)” to show or hide the per-bot picker details. Per-bot and global model controls remain disabled until the hub implements the reviewed contract and model changes are separately authorized.
